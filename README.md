## 🚀 Featured Projects

### 1. Machine Learning for Battery Electrode Materials
Developed a deep learning framework to screen and predict the average intercalation voltages of candidate electrode materials for lithium-, sodium-, and potassium-ion batteries.

- Screened over 4,300 candidate materials using data from the Materials Project.
- Applied Composition-Based Feature Vectorization (CBFV) for materials representation.
- Developed a Deep Neural Network (DNN) predictive model.
- Achieved an **R² of 0.89 and an MAE of 0.26 V**.

### 2. Machine Learning for Sustainable Catalysts for CO₂ Conversion
Explored machine learning approaches for predicting adsorption energies and catalytic performance in CO₂ reduction and hydrogen evolution reactions.

- Worked with experimental catalyst datasets, including FAIR-Chem and OCx24.
- Investigated materials descriptors and adsorption-energy relationships.
- Applied machine learning models, including Random Forest and Linear Regression.
- Explored data-driven methods for sustainable catalysis.

### 3. AI-Based Transformer Fault Detection System
Contributed to developing an intelligent fault detection system for electrical transformers using real-world operational data from Ghana Grid Company (GRIDCo).

- Processed and structured time-series transformer data.
- Developed and evaluated multiple machine learning classification models.
- Identified XGBoost as the best-performing model for the selected evaluation criteria.
- Deployed an interactive Streamlit application for fault prediction, visualization, and reporting.
